# Pagefold 📸
### Бесплатные скриншоты всей страницы для Google Chrome, с редактором и экспортом в PDF

> **Pagefold** — расширение для Google Chrome (Manifest V3). Снимает страницу целиком, видимую область, выделенный фрагмент или отдельный элемент. Снимок можно обрезать, подписать, замазать и сохранить в PNG, JPG, WebP или PDF.
> Бесплатно, без регистрации и без рекламы. Скриншоты хранятся в вашем браузере, расширение никуда их не отправляет.
>
> Часть [Morlov](https://morlov.app) — небольших бесплатных инструментов, которые делает один человек.

## 🛠️ Возможности плагина

### 1. Режимы захвата
- **Вся страница (Full Page)**: автоматическая плавная прокрутка всей страницы, умная пауза для динамической подгрузки изображений и контента (Lazy Load), аккуратное скрытие плавающих/прилипающих меню (sticky headers) и бесшовное склеивание на Canvas в исходном качестве (включая Retina / 4K экраны).
- **Видимая область (Visible Viewport)**: мгновенный снимок экрана в 1 клик.
- **Выделенная область (Selected Area)**: интерактивное выделение прямоугольной области мышью с отображением размеров в пикселях.
- **Выбранный элемент (DOM Element)**: наведение курсора с подсветкой любого блока/карточки/статьи на странице и захват только выбранного элемента. Стрелки `↑`/`↓` переключают на родительский/дочерний элемент, `Enter` или клик подтверждают, `Esc` отменяет. Элементы выше экрана снимаются целиком с автопрокруткой.

### 2. Встроенный графический редактор (100% Free)
- **Обрезка (Crop)** с сеткой третей и индикатором разрешения в пикселях.
- **Пикселизация (Redact / Blur)**: быстрое скрытие паролей, номеров карт, личных переписок и персональных данных.
- **Стрелки и Линии**: аккуратные направляющие стрелки с наконечниками.
- **Фигуры**: Прямоугольники и Овалы с поддержкой заливки или контура.
- **Текст**: размещение текстовых надписей с контрастной подложкой.
- **Счетчик шагов (Step Badges)**: автоматические бейджи с номерами `1`, `2`, `3`... для оформления баг-репортов и пошаговых инструкций.
- **Маркер-хайлайтер**: полупрозрачное выделение текста и элементов.
- **Карандаш / Свободное рисование**: выбор толщины и цвета.
- **Поворот на 90° и Отражение (Flip)** по горизонтали.
- **История изменений**: отмена и повтор (`Ctrl+Z`, `Ctrl+Y`).

### 3. Экспорт и скачивание
- **PNG**: максимальное исходное качество без потерь.
- **JPG / WebP**: регулируемый ползунок качества (30% - 100%) для экономии места.
- **PDF**:
  - **Многостраничный документ**: нарезка длинной страницы на стандартные листы A4 или US Letter с настраиваемыми полями, верхним колонтитулом (название и ссылка) и нумерацией страниц («Стр. 1 из 5»).
  - **Непрерывный длинный лист**: единый PDF-файл, идеально повторяющий веб-страницу.
- **Копирование в буфер обмена (Copy to Clipboard)**: мгновенная вставка скриншота в мессенджеры (Telegram, Slack), почту или Figma.

### 4. Локальная галерея истории (IndexedDB)
- Все сделанные скриншоты безопасно сохраняются в локальной базе данных браузера.
- Быстрый просмотр миниатюр, даты, размера файла и разрешения.
- Мгновенный поиск по заголовку страницы или URL.
- Очистка истории и статистика занятого места.

### 5. Горячие клавиши (Keyboard Shortcuts)
- **`Alt + Shift + P`** — Снимок всей страницы целиком
- **`Alt + Shift + V`** — Снимок видимой области
- **`Alt + Shift + S`** — Снимок выделенной области
- **`Alt + Shift + E`** — Снимок выбранного элемента

## 📦 Установка в браузер (Chrome, Brave, Edge, Yandex, Opera)

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/mpishchaev/pagefold.git
   ```
   *(или скачайте ZIP со страницы репозитория и распакуйте)*

2. Откройте в браузере страницу расширений:
   - В Google Chrome / Brave: `chrome://extensions/`
   - В Microsoft Edge: `edge://extensions/`
   - В Яндекс.Браузере: `browser://tune/`

3. Включите переключатель **«Режим разработчика»** (Developer mode) в правом верхнем углу.

4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.

5. Выберите папку проекта:
   папку `pagefold`, в которой лежит `manifest.json`

6. Готово! Иконка **Pagefold** появится в панели расширений. Для удобства закрепите её булавкой (Pin).

## 🔒 100% Приватность и Безопасность

- **Никаких внешних серверов**: расширение не делает ни единого сетевого запроса наружу.
- **Никаких сторонних скриптов с CDN**: библиотека `jsPDF` включена непосредственно в исходный код расширения (`lib/jspdf.umd.min.js`).
- **Никакой телеметрии и аналитики**: ваши скриншоты, посещенные ссылки и документы никогда не покидают ваш компьютер.
- **Соответствие стандарту Google Chrome Manifest V3**: строгие политики безопасности без использования `eval()` или удаленного кода.

## 📂 Структура проекта

```
pagefold/
├── manifest.json              # Манифест расширения Manifest V3
├── package.json               # Метаданные и скрипты
├── README.md                  # Документация и инструкция
├── _locales/                  # Мультиязычность (Русский и Английский)
│   ├── en/messages.json
│   └── ru/messages.json
├── icons/                     # Иконки всех размеров (16, 32, 48, 128 px)
│   ├── icon16.png
│   ├── icon32.png
│   ├── icon48.png
│   ├── icon128.png
│   └── icon.svg
├── lib/                       # Локальные библиотеки
│   └── jspdf.umd.min.js       # Автономный генератор PDF
├── background/                # Фоновый Service Worker (MV3)
│   └── service_worker.js      # Координация захвата, горячие клавиши, меню
├── content/                   # Контентный скрипт
│   ├── content.js             # Прокрутка, скрытие sticky, HUD прогресса
│   └── overlay.css            # Стили интерфейса на странице
├── popup/                     # Всплывающее окно быстрого запуска
│   ├── popup.html
│   ├── popup.css
│   └── popup.js
├── viewer/                    # Страница просмотра и полного редактора
│   ├── viewer.html            # Холст, интерфейс, модальные окна
│   ├── viewer.css             # Стили редактора (Dark/Light темы)
│   ├── viewer.js              # Контроллер просмотрщика
│   ├── editor.js              # Движок редактора (Crop, Redact, Shapes, Text)
│   ├── pdf-exporter.js        # Модуль экспорта в PDF
│   └── history.js             # Модуль управления историей снимков
├── utils/                     # Утилиты
│   ├── storage.js             # Настройки и шаблонизатор имен файлов
│   ├── db.js                  # База данных IndexedDB для скриншотов
│   └── stitcher.js            # Движок сшивания Canvas
└── tests/                     # Тесты целостности
    └── test_extension.js      # Набор проверок всех модулей
```

## 🧪 Запуск тестов

Для проверки целостности всех файлов расширения и алгоритмов выполните команду:
```bash
node tests/test_extension.js
```
Эти тесты проверяют наличие файлов, спецификацию Manifest V3, шаблонизацию имен и локализацию.

Захват в настоящем Chromium с попиксельной проверкой результата:
```bash
PLAYWRIGHT_CORE=<папка playwright-core> CHROMIUM=<путь к chrome.exe> npm run test:e2e
```
